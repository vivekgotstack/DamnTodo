<h1 align="center">📝 TodoApp</h1>

A **smart, persistent Todo app** built with **React, TypeScript, and Redux**.  
Never lose your edits — even if you refresh mid-task, your changes are saved automatically using **localStorage**.

---

## ✨ Features
- ✅ Add, edit, and delete tasks  
- ✅ Persistent storage: edits survive page refreshes  
- ✅ Intuitive, user-friendly interface  
- ✅ Built with **React**, **TypeScript**, and **Redux** for reliable state management

## 💻 Getting Started

```bash
# Clone the repo
git clone https://github.com/vivekgotstack/TodoBitch.git
cd TodoBitch

# Install dependencies
npm install

# Run it
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

---

## 🎯 Why This App?
This TodoApp isn’t just a task list — it’s **smart, reliable, and elegant**.  
Even if you accidentally refresh the page, your edits are preserved.  
Perfect for practicing **React + Redux + TypeScript** best practices while building a real-world app.

---

## ⚡ Tech Stack
- **React**  
- **TypeScript**  
- **Redux**  
- **localStorage** for persistence  
- **CSS/Styled Components/Tailwind** (depending on what you used)
